# 🤖 Orquestração de Agentes & Prompts

Este diretório gerencia a inteligência generativa, cadeias e regras pedagógicas do sistema.

### Responsabilidades:
- Engenharia de prompts estruturados por perfil de público e formato educacional.
- Cadeias de execução (LangChain) ou fluxos com grafos (LangGraph).
- Integração com provedores de LLM (Google Gemini, OpenAI, Claude, etc.).
- Verificação de fidelidade à fonte (grounding) para mitigação de alucinações.
