# 🤖 Orquestração de Agentes & IA Conversacional

> 🚧 **Feature Pós-MVP** — Este módulo está reservado para a implementação futura de um agente conversacional (IA interativa). Não faz parte do escopo do MVP atual. A decisão de manter esta pasta é intencional: ela documenta o roadmap arquitetural do projeto.

---

Este diretório gerenciará a inteligência generativa avançada, cadeias de agentes e regras pedagógicas do sistema na fase pós-MVP.

### Responsabilidades previstas (pós-MVP):
- Engenharia de prompts estruturados por perfil de público e formato educacional.
- Cadeias de execução com LangGraph para fluxos conversacionais multi-turno.
- Integração com provedores de LLM (Google Gemini, Groq, etc.).
- Verificação de fidelidade à fonte (grounding) para mitigação de alucinações.
