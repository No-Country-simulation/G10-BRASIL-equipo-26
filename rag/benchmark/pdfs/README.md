# PDFs de entrada

Os PDFs originais não estão incluídos nesta entrega, para evitar redistribuição não autorizada.

Para reproduzir o benchmark, obtenha os cinco PDFs com permissão e coloque-os aqui, com os nomes exatos:
- `Deep_learning.pdf`
- `LLM.pdf`
- `Machine_Learning.pdf`
- `redes_neurais.pdf`
- `vcn.pdf`

O script usa o nome do arquivo para localizar `perguntas/perguntas_teste_<nome>.csv`.
