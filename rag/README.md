# 📚 Pipeline de RAG (Retrieval-Augmented Generation)

Este diretório é dedicado ao processamento, indexação e recuperação de contexto dos documentos técnicos.

### Responsabilidades:
- Ingestão e extração de texto (PDF, Markdown, texto bruto).
- Estratégias de segmentação de texto (chunking).
- Geração de embeddings vetoriais.
- Configuração e consulta ao Vector Store (ChromaDB, FAISS ou similar).
