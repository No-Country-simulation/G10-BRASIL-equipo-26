# 🚀 Backend & Endpoints da API

Este diretório contém a API REST da aplicação (FastAPI / Flask).

### Responsabilidades:
- Definição de rotas e endpoints (ex.: `/api/v1/adaptar-conteudo`).
- Validação estrita de contratos de entrada e saída de dados com Pydantic schemas.
- Tratamento de exceções e respostas padronizadas em formato JSON.
- Documentação interativa automática (Swagger/OpenAPI).
